# Methods outside the core

Consulted on demand: when the user names one, or when a phase needs a view the
core methods do not give. Each entry says when it beats the default.

## Optional deliverable views

**Lean Canvas, one page** (Ash Maurya). Render from the idea file, never as a
second source: a 3×3 markdown table with Problem · Solution · Unique value
proposition · Unfair advantage · Customer segments · Key metrics · Channels ·
Cost structure · Revenue streams. Empty boxes read `gap`.

**PR/FAQ — Working Backwards** (Amazon). Use when the idea has to be sold to
someone — a boss, a partner, an investor. A one-page press release dated at
launch (headline, the customer's problem, the solution, a customer quote, how to
start) followed by an FAQ split into customer and internal questions. The hard
internal questions come from CHALLENGE.

## Alternatives by phase

| Method | Origin | Phase | Use instead of the default when |
|---|---|---|---|
| Business Model Canvas | Alexander Osterwalder | REFINE | the idea extends an existing business, with partners and resources already in place |
| Value Proposition Canvas | Osterwalder, Strategyzer | REFINE | the differentiator is fuzzy: map jobs, pains and gains against pain relievers and gain creators |
| Opportunity Solution Tree | Teresa Torres, *Continuous Discovery Habits* | REFINE | there are several problems competing for one outcome, and the question is which to attack |
| Six Thinking Hats | Edward de Bono | CHALLENGE | a group is discussing the idea and the debate is mixing facts, feelings and critique |
| Kano model | Noriaki Kano | REFINE | the cut for v1 is between features: basic, performance or delight |
| RICE | Intercom | REFINE | several candidate options need a rough ranking by Reach, Impact, Confidence and Effort |
| TAM / SAM / SOM | market sizing practice | FIT | a `business` idea needs a sized market for a pitch; each number carries its source or is labeled hypothesis |
| Double Diamond | UK Design Council | all | the user asks where they are in the process: EXPLORE and CHALLENGE are the problem diamond, REFINE and FIT the solution diamond |
